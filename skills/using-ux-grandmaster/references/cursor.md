# Cursor

- **`uxg` path:** the plugin's `scripts/uxg.mjs`: two folders up from this skill's folder.
- **Subagents:** UX Grandmaster's agents are installed from the plugin's `agents/` folder: `design-critic`, `accessibility-auditor`, `research-scout`, `usability-walker`. If subagents are not available in your mode, use the fresh-eyes fallback in `critiquing-designs`.
- **Questions:** ask one framing question at a time in chat and wait for the answer.
- **Short commands:** `/brief`, `/research`, `/critique`, `/a11y`, `/handoff` if your Cursor version lists plugin commands; otherwise ask in words.
