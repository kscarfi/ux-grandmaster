# Antigravity

- **`uxg` path:** the plugin's `scripts/uxg.mjs`: two folders up from this skill's folder.
- **Subagents:** UX Grandmaster's agents are in the plugin's `agents/` folder. If they cannot be started, use the fresh-eyes fallback in `critiquing-designs`.
- **Always-on rule:** the plugin's `rules/AGENTS.md` reminds the agent to use UX Grandmaster on design work.
- **Short commands:** Antigravity has no plugin commands. Ask in words.
