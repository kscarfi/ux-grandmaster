# UX Grandmaster

A design methodology for AI agents. UX Grandmaster makes Claude work like a senior product designer: it frames the problem before designing, uses evidence, designs inside your design system and your platform's guidelines, gets an independent critique, checks accessibility against WCAG 2.2 AA, and refines everything it generates before you see it.

For designers at every level, developers checking their own apps, researchers, and design leaders: 40 skills and 4 subagents, chosen automatically from your message and what you attach (a Figma link, a screenshot, code, interview notes, a CSV).

This is the directory edition: skills and agents only. The full edition adds the `uxg` scripts (contrast, axe, code scan, Figma REST, funnel and A/B statistics), a session hook and the eval suite: https://github.com/kscarfi/ux-grandmaster
