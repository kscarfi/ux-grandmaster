UX Grandmaster

Privacy policy

Last updated: 22 November 2026

UX Grandmaster does not collect, store or send any data. It has no servers, no accounts, no analytics and no telemetry.

Personal data

Some skills read content you give your AI agent that can contain personal data, for example interview notes with participant details, or comments in a design file with author names. UX Grandmaster does not store this content anywhere. The skills tell the agent to remove personal data from findings it shares, and not to put research participant data into tools that are not approved for it.

What runs where

  • Skills and agents are instructions that your AI agent reads. They run inside your agent, under your agent provider's own privacy terms.
  • Web pages. Some skills ask your agent to read official design guidelines (for example developer.apple.com, developer.android.com, w3.org and nngroup.com) with the web tools your agent already has, with your permission. No data about you is sent to these sites.
  • Design tools. If you connect Figma or another design tool to your agent, the skills use that connection's tools to read designs. Before any write or publish action in such a tool, the agent asks you first.

Optional local scripts

The full edition on GitHub also includes the uxg command-line scripts. They run only on your own computer:

  • uxg setup downloads Playwright, axe-core and a Chromium browser from the npm registry and Playwright's download servers.
  • uxg library indexes design books and papers you choose into a folder on your computer. Nothing leaves your machine.
  • uxg figma reads Figma files with a personal access token you set in your own shell. The token is sent only to api.figma.com and is never stored or printed.

Editions published in plugin directories may contain skills and agents only, without these scripts.

Children

UX Grandmaster is made for professionals and is not intended for people under 18.

Changes

Changes to this policy are published on this page and in the project's history on GitHub.
